What is Meldwork?

Meldwork is a local-first multi-Agent collaboration workspace for research, analysis, writing, planning, review, and implementation. Selected Agents advance the same task through discussion, authorized execution, and peer review. You set the boundaries and make key decisions when needed.

HOW MELDWORK DIFFERS

Spend less time managing the handoffs.

Meldwork brings the Agent tools you already run into a local-first collaboration workspace. Let the group discuss and advance the task, while you focus on the goal, boundaries, and key decisions.

  • Agents coordinate the next contribution

    Agents can request a peer's input or review, and the delivery owner judges whether more work or a user decision is needed.

  • Authorized execution and peer review

    Enable workspace writes for implementation tasks. Agents can carry out work within that scope and ask peers to check the deliverables.

  • Local-first boundaries

    Runs in your Electron work cell with existing CLIs. No cloud Agent fleet, no required server, conversations stay local.

  • Shared context and local history

    Keep the brief, peer replies, run state, and deliverables together so you can revisit progress and continue the work.

THE BOUNDARY

What Meldwork is, and isn't.

Is

  • A local-first desktop workspace for multi-Agent collaboration.
  • A working group built from the Agent CLIs you select.
  • Shared context, authorized execution, peer review, and local run history.
  • Workspace writes as opt-in workflow controls.
  • Source-available under the Meldwork Non-Commercial Source License 1.0.

Isn't

  • Not a hosted Agent fleet or general Agent framework.
  • Not automatic participant selection from a larger roster.
  • Not a guarantee that every task finishes without your input.
  • Not an operating-system sandbox — writes happen through your shell.
  • Not fully offline — a selected Agent may send prompts to its own CLI provider.

ANSWERS

Questions teams ask before adopting.

Short, honest answers — the long versions live in architecture.md ↗.

  • Meldwork is a local-first multi-Agent collaboration workspace for macOS. It brings your existing Agents into one working group to share context, discuss approaches, carry out authorized work, and check results. You choose the participants, set goals and permissions, and step in when information or key decisions are needed.

  • Meldwork stores conversations and coordinates work locally. Selected Agents may send prompts, attachments, or Skills to the model provider configured in their own CLI. Local-first describes where Meldwork stores and coordinates the work; it does not mean the model runs offline.

  • Twelve today — Codex, Claude Code, Gemini CLI, Qwen Code, Kimi Code, MiMo Code, OpenCode, OpenCodeReview, Hermes, Pi Agent, OpenClaw, and WorkBuddy. Approved Agent Connectors can be added through the Agent Connector SDK; custom executables use the desktop custom-Agent path.

  • Selected Agents start with independent proposals, then discuss differences, request peer contributions, carry out authorized work, and check deliverables. A delivery owner judges progress and whether more work or a user decision is needed. You do not need to direct every round, but missing information, permissions, or key decisions can still require your input.

  • Meldwork adds task-level collaboration across selected Agent CLIs: shared context, peer discussion, requests for further contributions, authorized execution, and review of deliverables. This reduces the work of relaying replies and coordinating next steps yourself. Collaboration history and run state stay local so you can revisit progress and blockers.

  • You choose the Agents, goal, context, and permissions. Auto Discussion lets Agents advance the work without you directing each turn, but missing information, permission requests, or key tradeoffs may require your input. Workspace writes are opt-in. Check important deliverables before using them; peer review does not guarantee correctness.

  • Source-available under the Meldwork Non-Commercial Source License 1.0. You can inspect, run, modify, and share it for non-commercial purposes. Commercial use requires prior written permission — see COMMERCIAL_USE.md ↗.

  • The current V1.0.6 preview targets Apple silicon macOS (ad-hoc signed, not notarized — open Open Anyway in System Settings → Privacy & Security on first launch). Cross-platform builds are on the roadmap; the app is Electron so the same source compiles everywhere once those targets land.
