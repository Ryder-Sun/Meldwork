日期：2026-10-20。工作分支：`1.0.7`。

## 产品调整

- 私聊、群聊均移除 Tasks & delivery 入口、面板和发送绑定，恢复标题、消息、输入区三行布局。
- 历史交付数据和后端存储保留，避免删除用户文件；移除已失去入口的前端组件和旧交付 UI smoke。
- 左侧导航保留 `overflow: auto`，隐藏滚动条；执行详情、设置页仍保留原有细滚动条。
- 首次使用增加可跳过的工作偏好页；通用设置可随时修改。包含三种起点、交付详略、推进方式、证据要求、最多 8 个协作者偏好、800 字以内补充说明。
- 保存通过受信任 preload IPC 进入主进程，严格校验并持久化；运行中禁止修改。默认设置不额外注入提示词，自定义偏好提示限制在约 1500 字符以内。偏好不能授予写权限，不能自动添加参与者。

## MiMo

原因：`mimo providers whoami` 的官方账号登录状态不能代表当前自定义 Provider 是否可用。本机选择了原生配置中的自定义 Provider，但旧检测将其判为未登录。

修复：检测 MiMo 原生配置中当前选择的 Provider 是否具有可用配置，不修改原生 model、baseURL 或密钥，不注入任何固定模型。凭据不返回渲染进程。

实测：原生二进制 0.1.0 经生产 ACP 适配器完成首次调用和会话续接；隔离 Electron 用户目录下，经真实主进程完成 MiMo 与一个确定性测试协作者的群聊调用。测试未改动用户日常工作区。

限制：这是当前本机配置的成功证据，并不证明所有 Provider、平台或所有凭据引用形式均兼容。

## WorkBuddy

客户端 2.161.0 随附的是独立 lite CLI。原生桌面账号使用宿主管理的加密凭据，独立 CLI 不能直接解锁。不得将“客户端已登录”简单当作“独立 CLI 可调用”。

本次改动：准确区分账号未验证、桌面凭据受保护、所选 Provider 鉴权失败；不默认选择第一个模型，也不包含 glm 或任何机构模型作为默认值。显式选择本机已有模型仅作为折叠的高级兼容选项，Meldwork 只持久化模型 ID。此前该兼容路径已完成真实直接调用、续接和群聊验证，但它不等于自动复用桌面账号和桌面当前模型。

官方方案核对：

- [WorkBuddy Open API](https://open.workbuddy.cn/en/docs/openapi)：接入要求注册第三方应用、取得 clientId/clientSecret，并由用户完成 OAuth 授权。文档明确 clientSecret 不得暴露在客户端代码中。
- Local Assistant API 的调用地址是 `https://www.workbuddy.cn/openapi/v2/localassistant`，经 WorkBuddy 服务转接 PC 助手，并不是公开的本地进程协议。

未完成：自动沿用 WorkBuddy 桌面账号和当前模型。当前缺少已注册应用身份；官方方案还涉及云端转接及保密客户端凭据，与 Meldwork 当前无需服务器的产品边界存在冲突。本次没有加入必需服务器、复制桌面令牌、关闭认证或伪造成功状态。

## 群聊共享上下文：保证与限制

已经具备且本次验证的机制：

1. V4 调度冻结公共任务快照，以 snapshotHash 绑定任务、历史和参与者。所有参与者读取同一公共任务基线。
2. 每次调用还携带当时可见的讨论记录。原生会话分别归属于各 Agent；顺序执行时，后执行者会看到前执行者的新回复，因此完整提示词不应逐字相同。
3. 增量交付回执按原生 Session、Run、快照和来源正文哈希隔离。已确认的完整消息可跳过；摘录不得确认成“已读全文”。重启后仍复用持久化回执。

本次优化：

- 公共讨论正文预算由 48000 降至 16000 字符，单条上限 2400；按参与者数量分摊预算，避免高频发言者挤掉其他协作者。
- 采用确定性原文摘录，优先保留约束、否定、决定、来源及未决分歧，合并完全重复的句子。保留来源消息 ID 和原始顺序。
- 原始消息仍在本地保存。摘录和省略明确提示，不能据此推断达成一致或任务完成。
- 快照历史保留最早两条用户消息及最近历史，在最多 16 条内降低早期约束被后续讨论挤掉的概率。

固定评测样本：32 个协作者、每人包含大量重复背景、来源与未决事项，原文合计 338018 字符，交付 6512 字符，减少 98.07%。32 个协作者均被保留，32 条均标为摘录，完整消息确认数为 0。数字为字符，不是 tokenizer 统计，也不是普遍场景压缩率。

准确性样本验证：中部预算约束、否定决策、来源 URL、供应商冲突原文保留；三个参与者均得到同一冻结任务和早期隐私/预算要求；原始快照不被修改。另有实际调度、跨会话隔离和重启回执测试。

结论边界：共享的是可核验的公共任务和讨论事实，不是共享模型内部记忆。提取式压缩避免生成不存在的结论，但仍可能漏掉没有明显标志的事实；超长单句仍可能截断。有限预算无法保证任意历史全部保真，测试也不能证明模型最终交付质量必然提高。后续若引入语义摘要，应以事实召回、否定/分歧保真和来源可追溯为准入条件。
